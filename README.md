
# 🚀 John Dev - Personal Portfolio  

Welcome to the **John Dev** personal portfolio repository! This website serves as a **showcase of skills, experience, and projects**, providing a platform for visitors to learn more and get in touch. Built with **HTML, CSS, and JavaScript**, it features a **clean, responsive, and user-friendly design**.  

## 📑 Features  

- **🛠️ Skills Section** – Displays logos of various programming languages and tools.  
- **📂 Projects Section** – A space to showcase past and future projects.  
- **✉️ Contact Section** – Allows visitors to reach out via a contact form or provided links.  
- **📱 Responsive Design** – Ensures seamless viewing across different screen sizes.  

## 🛠️ Technologies Used  

- **HTML5** – Provides the structure of the website.  
- **CSS3** – Handles styling, including layout, fonts, and colors.  
- **JavaScript** – Adds interactivity and dynamic user experience.
